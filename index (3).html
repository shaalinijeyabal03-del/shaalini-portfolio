Internet of Things / Embedded Systems

IoT-Based Invisible Keypad for ATM Privacy

An academic project focused on improving ATM transaction privacy through an invisible keypad concept. When people enter a PIN at an ATM, the keypad can be observed by others. This project explores a privacy-oriented input mechanism so that the keypad is not openly visible.

The system combines electronic hardware (a microcontroller with sensors and a display) with software components (a Python and Django application with a MySQL database and OTP-based authentication) to form a complete, security-oriented prototype.
